# Hosted RTL primitives

The independently authored native runtime now handles five kernel imports present in the original dashboard/XAM inventory: RtlCompareMemory (011A), RtlCompareMemoryUlong (011B), RtlFillMemoryUlong (0126), RtlInitAnsiString (012C), and RtlInitUnicodeString (012D). The interface reference is ReXGlue SDK a3e1d82678ca20d68d4837a8e9ee4652ff073745, xboxkrnl_rtl.cpp. Its comparison model counts equal positions (bytes or words), not an initial matching prefix. This is a compatibility-model choice pending original kernel differential evidence, not a proven retail result. Words and descriptors are big endian. Fill accepts aligned, complete words; string descriptors contain byte length, maximum byte length including terminator, and guest pointer. Null and empty nonnull sources are distinct. Lengths exceeding the 16-bit descriptor capacity are rejected, not truncated. Invalid guest accesses return a fault without publishing a result; memory fill is a single atomic write in the independent AddressSpace implementation. Transfers are capped at 16 MiB. Synthetic tests cover non-prefix equality, boundary crossings, atomic failure and both string encodings. These services are not connected to the separate AOT host.
