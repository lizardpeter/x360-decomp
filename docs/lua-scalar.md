# First original dashboard Lua execution

The authored bounded scalar evaluator implements a subset of Lua 5.1 register operations. The eligible original functions have no captured upvalues, nested prototypes, global/table operations, calls, or variable-length returns. Their code is verified before execution. Arithmetic uses binary64, strings retain byte lengths including embedded NUL, truthiness treats only nil and false as false, and conditional skips and numeric loops are modeled. No native host functions, metamethods, number-to-string or string-to-number coercion, or locale-dependent string ordering are implemented. Type rejections reflect this restricted evaluator, not necessarily original Lua runtime errors. Execution has step and per-string length limits; it is not a general hostile-code sandbox.

Independent local Python analysis of the digest-verified dashboard identified 61 eligible prototypes (259 words), including duplicated functions across script archives. Twenty deterministic scalar argument choices per prototype give 1,220 cases: 1,114 returns and 106 restricted-type rejections. The native audit hashes the serialized result stream against the independent Python reference. This is original-bytecode-derived subset execution, not a hardware differential run or completed Lua VM. Original chunks and return values remain local; only counts and digest are published.
