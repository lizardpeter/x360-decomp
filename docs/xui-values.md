# Typed XUI scene data and geometry

Independent inspection of all 363 original scenes identifies FLOT as big-endian float words (5,621), VECT as 3-component floats (5,206), QUAT as 4-component floats (87), and COLR as packed words (786). Two zero quaternions are retained exactly; no normalization is applied. Every observed float is finite.

CUST is a sequence of length-prefixed records: big-endian float width, float height, u32 count and count times six big-endian floats. All 258 records match this grammar; 1,057 segments. Independent evidence: rectangle records contain four endpoint transitions, and rounded shapes contain curved control points. A candidate closed cubic interpretation uses the final endpoint as the starting point and each six-float tuple as two control points plus endpoint. This is a testable interpretation, not verified original tessellator behavior. Adaptive subdivision provides portable polyline output and reports tolerance failures instead of silently producing low-quality output. Fill triangulation, gradients, and rendering are not implemented.

The owning resource catalog validates extents, nonoverlap and duplicate resource IDs. Views retain validity when the catalog is move-constructed; callers must retain the catalog lifetime. Lookup is exact and virtual, not file system resolution. The audit reads all original scene value tables and constructs contours; no original asset is committed or published. The XAM source dependency on formats is intentional. DATA, custom properties, keyframe binding, scene element trees and Lua execution still require reconstruction.
