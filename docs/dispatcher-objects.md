# Hosted dispatcher object subset

The independent runtime implements the address-based event and semaphore subset of the original kernel import inventory. It supports KeInitializeEvent (0070), KeInitializeSemaphore (0074), KeResetEvent (008F), KeSetEvent (009D), KeReleaseSemaphore (0088), and KeWaitForSingleObject (00B0) under restricted nonblocking conditions. Interface/structure reference: pinned ReXGlue SDK a3e1d82678ca20d68d4837a8e9ee4652ff073745, kernel types/thread.h and xboxkrnl_threading.cpp. This is a host-side model, not reconstructed original kernel code or scheduler parity. A 16-byte dispatcher header contains type, big-endian signal state, and self-referential empty wait-list links; semaphores add a 32-bit limit. Manual events retain their signal after a successful wait, automatic events consume it, and semaphores decrement. An unsignaled zero-timeout wait returns STATUS_TIMEOUT; a blocking wait, alertable operation, waiter list, invalid record, semaphore overflow, or wait-on-release request remains unresolved rather than pretending to succeed. No handle API, concurrency, object lifetime, APC delivery or real wait queue is included. This subset is not connected to the AOT host yet.

The immediate KeWaitForMultipleObjects (00AF) subset validates up to 64 independent event/semaphore records before making any state changes. WaitAll consumes all eligible objects only after every object is signaled; WaitAny consumes the first eligible object and returns its index. A zero timeout can return STATUS_TIMEOUT without changing any object. KePulseEvent (007F) clears an event when its waiter list is empty and returns its previous state. Existing limitations remain: no blocking, real wait queues, duplicate/overlapping wait records, alertable waits, APC delivery or scheduler. Multi-object mutation requires the single-threaded AddressSpace provider, with all target writes checked before consumption. These services remain independent of the AOT host.
