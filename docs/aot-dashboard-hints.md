# Verified additional dashboard function-start hints

The initial ReXGlue v0.11.0 dashboard trial failed before emitting source. The older independent x360-native v1.34.6 project documents function discovery gaps in its dashboard 17559 analysis (BSD-3-Clause; https://github.com/fabegalo/x360-native, titles/dash_17559/analysis/dash_17559.toml). Its 30 entry-address annotations were treated as candidate locations, not copied runtime code. We independently decoded the exact basic-compression original to SHA-256 06a8446849184331dc1b513a894c08ad3f160dcec8473f70cdcae9f54b7c86f9, reconstructed the original 28,350 pdata ranges, scanned the executable section for direct non-link branches and recorded the exact incoming references. Every candidate is aligned, executable and outside all pdata ranges. All candidates have one or more direct tail-branch references. The scan is conservative evidence, not full function-boundary proof: executable sections can contain embedded data, and a direct branch may target an internal chunk. The strict translator must still validate the proposed starts.

The new independent original-image audit checks the exact reference list and emits a build-local manifest include with only start addresses. No forced sizes, instruction changes, external hooks, privilege modifications or copied generated source are introduced. This trial is separate from the unhinted code-generation and compile/link gates. The prior failure categories did not retain a specific explanation; these hints are a testable discovery hypothesis, not proof of its root cause.
