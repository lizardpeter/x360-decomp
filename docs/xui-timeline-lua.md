# Original named timeline and Lua chunk structure

Independent inspection of original version-8 XUIB NAME records established a compact unsigned integer encoding: 0..239 are one byte; 0xF0..0xFF encode the upper four bits followed by the lower eight bits. NAME records contain a one-based STRN name reference, frame position, and kind. Observed kinds 0 and 1 have no extra field; 2, 3, and 4 include a second one-based STRN reference. No playback meaning is assigned to the kinds. Multiple timelines can reuse the same name, so lookup preserves every occurrence. The eight legacy scenes have no NAME section. Original NAME census is checked by the native system audit; KEYP/KEYD channel and interpolation semantics and DATA hierarchy remain unreconstructed.

All 204 dashboard LUB files use the Lua 5.1 big-endian 32-bit int/size_t/instruction and 64-bit floating-number ABI. The native reader parses source strings, prototype trees, original instruction words, typed constants, local lifetimes, line and upvalue debug metadata. It preserves number bits and embedded NUL bytes. It validates lengths, recursion depth, opcode range and SETLIST extension-word framing, and never executes input. Independently measured original totals: 2,441 prototypes, 63,166 words, 22,032 constants, 25,924 encoded non-null strings, depth 5, 5,773 local records. The audit checks per-opcode and constant-type totals, including zero observed SETLIST extensions; the synthetic test covers that extension. This is a structural reader, not complete bytecode verification, Lua interpreter, or execution of dashboard scripts. Original source bytes, strings and bytecode remain local.
