# AOT host compilation trial

The original standalone XAM code-generation trial succeeded (68 C++ translation units, 143 total files, 73,197,997 generated bytes). Dashboard code generation failed before producing files. The initial workflow intentionally did not export full codegen logs, so the exact failure was not retained. This follow-up collects error categories and guest addresses only to make the failure actionable, and compiles successful generation outputs using the pinned SDK package and its documented Clang 20 / GCC 13 libstdc++ ABI.

The separate trial uses the public SDK TitleApp interface and a minimal CMake host target. It does not yet combine dashboard and XAM or integrate authored kernel functions. The standalone XAM executable is a compile/link gate, not a claim that XAM can launch as a title. Codegen, compile/link, boot, and interactive dashboard are distinct gates. All originals and generated code/binaries remain in ignored local build directories; CI uploads only metadata. No guest execution or privilege override is requested in this trial.
