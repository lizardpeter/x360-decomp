# Original Lua 5.1 instruction and control-flow validation

The native control-flow verifier distinguishes logical instructions from CLOSURE capture operands and SETLIST extension words, checks static register, RK, constant, child and upvalue indices, and validates normal intraprocedural successor targets. Test and comparison instructions require the observed paired JMP; control flow cannot land inside capture operands. The graph includes both possible conditional edges without attempting dataflow or constant folding. Call/return behavior, variable-top analysis, exception edges and runtime value semantics are not modeled.

An independent local scan of all 204 original chunks finds 2,441 prototypes, 62,334 logical instructions, 832 closure capture words, 62,384 normal-flow edges, 4,440 conditional nodes, 4,390 terminal nodes and 60,744 conservatively reachable instructions. The 1,590 unreachable logical instructions are retained. This is not a guarantee of arbitrary bytecode safety: the native verifier is a bounded structural/operand/branch audit and not a Lua sandbox or VM. No original script execution is performed. Synthetic regressions cover malformed captures, branches, operand ranges and unreachable code. The native original audit checks each aggregate count against the independent scan.
